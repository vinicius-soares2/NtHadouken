# NtHadouken Papers

Bem-vindo ao repositório de **Papers do NtHadouken**! Este projeto é dedicado a compartilhar trabalhos que desenvolvo, com o objetivo de ajudar iniciantes a compreender melhor os componentes internos do Windows (Windows Internals).

## Objetivo

O principal objetivo deste repositório é fornecer **materiais educativos aprofundados** sobre diversos tópicos relacionados aos internals do Windows. Cada paper é cuidadosamente elaborado para ser acessível a iniciantes, permitindo que eles adquiram uma compreensão sólida dos conceitos fundamentais e ganhem confiança em explorar o funcionamento interno do sistema operacional Windows.

### Tópicos abordados:

- **Processos e Threads**
- **Gerenciamento de Memória**
- **Interrupções e Exceções**
- **Gerenciamento de Dispositivos**
- **Segurança e Proteção**
- **Exploração de baixo nível (Low-Level)**
- **E muito mais...**
